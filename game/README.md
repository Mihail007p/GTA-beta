# Open Street — свободная езда и прогулки по городу

Открытый 3D-город: езда с аркадной физикой, трафик, дрифт и гараж, а также
выбор одного из двух героев, ходьба и бег. Игра начинается пешком рядом со своей
машиной. Можно сесть в неё или остановить и угнать машину трафика, а также
заходить в отмеченные магазины и дома. В магазине есть продавец, покупки и
заказы; дома можно готовить, лечиться и менять одежду. В городе ходят прохожие,
есть работы с пассажиром, маршрутами и уборкой, быстрый вызов такси и смена дня и ночи.
Прохожие реагируют на наезды. Машины гаража —
3D-модели Porsche Cayenne, 911 GT3 Touring, Ferrari 458 Spider и Porsche Carrera GT;
в городе — трафик из 8 типов машин.

Игра запускается в Chrome на Android, ставится на главный экран и после полной
первой загрузки может работать **без интернета**. Без рекламы, аккаунтов и аналитики.
Игровые файлы занимают около 9,7 МиБ, из них ~3,3 МиБ — машины гаража и
~5,1 МиБ — персонажи, одежда и движения.

## Как поставить на телефон

Игре нужен веб-сервер: если просто открыть `index.html` из «Файлов», Chrome не загрузит модули.
Выберите любой из трёх способов.

### Способ 1. Netlify Drop (самый простой, ~2 минуты, бесплатно)
1. На компьютере откройте **app.netlify.com/drop** (нужна бесплатная регистрация).
2. Перетащите в окно **папку `game`** целиком.
3. Netlify выдаст ссылку вида `https://что-то.netlify.app`. Откройте её на телефоне в **Chrome**.
4. Меню **⋮ → «Добавить на главный экран»** (или «Установить приложение»).
5. Запускайте с иконки: браузер постарается открыть игру без панелей. После успешной полной загрузки файлов она может работать без интернета.

### Способ 2. GitHub Pages (бесплатно, постоянная ссылка)
1. Создайте репозиторий на github.com и загрузите в него **содержимое** папки `game`
   (так, чтобы `index.html` лежал в корне).
2. **Settings → Pages → Deploy from a branch → main / root → Save**.
3. Через минуту игра будет доступна по адресу `https://<логин>.github.io/<репозиторий>/`.
4. Дальше так же, как в способе 1: Chrome → ⋮ → «Добавить на главный экран».

### Способ 3. С компьютера по Wi-Fi (без интернета, но и без офлайн-режима)
1. На компьютере установите Node.js и в папке `game` выполните:
   ```
   node tools/server.mjs
   ```
2. Узнайте IP компьютера в локальной сети (например, `192.168.1.5`).
3. На телефоне, подключённом к той же Wi-Fi, откройте `http://192.168.1.5:8080`.

> Офлайн-режим и установка на главный экран требуют **https**, поэтому в способе 3 они не работают:
> телефон должен быть в одной сети с компьютером.

### Публикация через Raw.githack

Для публичного репозитория ссылка на конкретный коммит выглядит так:
`https://rawcdn.githack.com/ВЛАДЕЛЕЦ/РЕПОЗИТОРИЙ/КОММИТ/game/index.html`.
CDN надолго кэширует файлы, поэтому для новой версии используйте новый хеш
коммита и новую ссылку. Raw.githack может сначала показать собственное
предупреждение и кнопку **Open the page**. Прогресс на другом домене
автоматически не переносится. Для манифеста используется `manifest.json`
(старый `manifest.webmanifest` сохранён для совместимости).

### Обновление и сохранения
После публикации откройте игру с интернетом и дождитесь загрузки. При необходимости
закройте и откройте её снова, чтобы установить обновлённый офлайн-кэш. Для офлайна
требуются HTTPS и успешная загрузка **всех** ресурсов в service worker.

Прогресс хранится в localStorage браузера и привязан к origin сайта (протокол, домен и порт).
Новый домен или другой браузер не перенесут его автоматически; очистка данных сайта может
его удалить. Новая ссылка Raw.githack с другим хешем использует тот же origin и сохранение.

### Полный экран
- **Во вкладке браузера** после загрузки нажмите «Нажмите, чтобы начать» — игра попросит
  полный экран и альбомную ориентацию. Это требует касания и разрешения браузера.
- Кнопка **«На весь экран»** доступна в меню и паузе; значок **⛶** есть и в игре,
  если она открыта в окне. На портретном экране тоже есть кнопка полного экрана.
- Если полный экран сбросился (например, жестом «назад»), игра встанет на **паузу**.
  «Продолжить» попробует снова развернуть её.
- Если браузер или оболочка не поддерживают полноэкранный режим, игра продолжит работать
  в окне. Попробуйте открыть ссылку в Chrome или добавить игру на главный экран;
  отображение системных полос и блокировка поворота зависят от устройства.

## Управление

| Где | Что |
|---|---|
| **◀ ▶** слева внизу | **Руль**. Короткое касание — подрулить, удержание — полный поворот. Палец можно катать между стрелками, не отрывая |
| ГАЗ (зелёная) | Газ |
| ТОРМОЗ (красная) | Тормоз, при остановке задний ход |
| РУЧНИК (оранжевая) | Ручник: срывает машину в занос |
| ❚❚ | Пауза (гараж, настройки, меню) |
| Свайп по свободной области справа | Осмотреться: свайп вправо поворачивает взгляд вправо, влево — влево |
| ВЫЙТИ / СЕСТЬ / УГНАТЬ | Выйти из остановленной машины / сесть в пустую / угнать машину трафика |
| ВОЙТИ / ВЫЙТИ у двери | Войти в отмеченный дом или магазин / вернуться на улицу |
| Кнопка действия у голубой метки в доме | Сесть, лечь или воспользоваться ближайшим предметом |
| ГОТОВИТЬ / ОДЕЖДА | Вторая кнопка у плиты или шкафа — рецепты и гардероб |
| ПОСАДИТЬ / ВЫСАДИТЬ ПАССАЖИРА | Кнопки работы таксистом рядом с клиентом и адресом назначения |
| ДОСТАВИТЬ / СОБРАТЬ МУСОР | Действия на очередной точке работы пешком |
| Значок рюкзака | Еда, аптечки, активный заказ и быстрый вызов такси |
| ВСТАТЬ или движение стиком | Подняться с дивана или кровати и продолжить движение |
| ТЕЛЕВИЗОР на диване | Включить или выключить телевизор, не вставая |
| Стик слева (пешком) | Ходьба относительно направления камеры |
| БЕГ (удерживать) | Бежать, одновременно управляя стиком |
| ⟲ | В машине — вернуть на дорогу; на улице пешком — вернуться к последней машине; в помещении — к выходу |
| ⛶ | Попробовать включить полный экран, если игра запущена в окне |

Палец можно **перекатывать** между кнопками, не отрывая: газ → ручник → газ.
Это основной приём для входа в поворот заносом.

Вместо стрелок можно включить старый **стик** (Настройки → Управление → Стик).

На компьютере: **WASD / стрелки** — руль или движение, **пробел** — ручник,
**Shift** — бег пешком, **E** — контекстное действие, **T** — телевизор с дивана,
**B** — рюкзак, **F** — готовка/гардероб у предмета, **R** — вернуть машину или героя.
Камера на сенсорном устройстве поворачивается свайпом справа.

## Как играть

- В меню откройте **ПЕРСОНАЖ**, пролистайте героев и нажмите **ВЫБРАТЬ**.
  Выбор записывается вместе с прогрессом. Существующие сохранения не сбрасываются.
- Начните пешком рядом со своей машиной. Подойдите к ней и нажмите **СЕСТЬ**;
  для выхода остановитесь и нажмите **ВЫЙТИ**. Чекпоинты и таймер цепочки пешком приостановлены.
- Ищите двери с вывеской и кольцом: бирюзовое **МАГАЗИН**, жёлтое **ДОМ**.
  Подойдите пешком и нажмите **ВОЙТИ**. Внутри можно ходить и осматриваться;
  для выхода подойдите к двери с надписью **ВЫХОД** и нажмите **ВЫЙТИ**.
  Вернёт к тому же фасаду; если место занято машиной, игра ищет свободное рядом.
  Пока игрок в помещении, уличное движение приостановлено, собственная машина остаётся на месте.
- В доме подойдите к голубой метке: справа появится кнопка действия. Можно сесть
  на диван, лечь на кровать, открыть книгу и шкаф, включить телевизор, свет, кран
  и плиту. С дивана телевизор переключается отдельной кнопкой. Чтобы подняться,
  нажмите **ВСТАТЬ** или сдвиньте стик. Состояния предметов сохраняются отдельно
  для каждого дома вместе с остальным прогрессом.
- У продавца у прилавка можно купить яблоко, хлеб, яйцо, аптечку и нарядный
  костюм. Деньги действительно списываются; ассортимент и все пять заданий видны
  при прокрутке списка. На старте, включая обновление старого сохранения, в
  рюкзаке есть по одному яблоку, хлебу и яйцу.
- Включите плиту основной кнопкой и нажмите **ГОТОВИТЬ**: хлеб + яйцо дают
  завтрак, хлеб + яблоко — фруктовый тост. Ингредиенты расходуются, готовую еду
  можно съесть в рюкзаке. Вещи не тратятся, если соответствующий показатель
  уже полный. У открытого шкафа кнопка **ОДЕЖДА** меняет купленный комплект.
- Здоровье и сытость показаны сверху. Сытость убывает на 1 за минуту **активной
  игры**, на паузе и в закрытой игре не убывает. При нуле голод отнимает здоровье;
  этот урон можно выключить в настройках. Еда и аптечка лечат, отдых на диване
  и кровати восстанавливает здоровье, пока сытость выше 5. Сильные аварии и
  наезды опасны. При потере здоровья герой приходит в себя с 50 здоровья.
- У продавца доступны пять оплачиваемых работ. Доставка в дом ($220) и поставка
  в магазин ($180): идите к жёлтой метке и нажмите **ДОСТАВИТЬ**. Маршрут
  курьера ($650): доставьте три посылки по очереди; уборка улиц ($360): пешком
  соберите три мешка у жёлтых меток кнопкой **СОБРАТЬ**. Вся оплата начисляется
  после последней точки. Сверху видны цель, расстояние и номер этапа.
- Работа **таксистом** ($380): возьмите её у продавца, сядьте в свою или угнанную
  машину и подъезжайте к ожидающему пассажиру у жёлтой метки. Остановитесь и
  нажмите **ПОСАДИТЬ**, дождитесь посадки, отвезите пассажира к следующей метке,
  остановитесь и нажмите **ВЫСАДИТЬ**. Если сбить ожидающего пассажира, заказ
  отменяется. Во время посадки машина не едет; при отмене поездки она останавливается,
  а пассажир выходит, если рядом есть свободное место.
- Одновременно активен один заказ. Его этап сохраняется после перезапуска; отменить
  можно в рюкзаке. Сама угнанная машина после перезапуска не сохраняется.
- Пешком на улице в рюкзаке можно вызвать такси: к дому/магазину за $40 или к
  адресу заказа за $60. Это **быстрый перенос с затемнением без анимации поездки**;
  личная машина остаётся там, где её припарковали.
- Часы и освещение следуют местному времени устройства: полный цикл составляет
  примерно 24 реальных часа. Вечером загораются окна и фонари. Прохожие ходят
  по тротуарам и отвечают короткой репликой на кнопку рядом с ними. Машины могут
  их сбить: после слабого удара человек встаёт, после сильного может погибнуть.
- Чтобы угнать автомобиль, остановите поток, встав перед машиной, затем подойдите
  к ней и нажмите **УГНАТЬ**. Если она едет слишком быстро, первое нажатие заставит
  водителя тормозить: подойдите и нажмите ещё раз. Водитель покидает машину и убегает.
- Собственная машина остаётся в городе, и к ней можно вернуться. Угнанные машины
  можно оставить и снова найти поблизости, но они не добавляются в гараж и не
  сохраняются после перезапуска; вдали оставленная машина может вернуться в трафик.
  Выбор в гараже меняет собственную машину, не текущую угнанную.
- По городу разбросаны **голубые кольца-чекпоинты** (стрелка на мини-карте и расстояние сверху).
  Каждое кольцо добавляет 13 секунд к таймеру цепочки и поднимает **множитель** (до ×8).
- Не успели к следующему кольцу — цепочка сбрасывается. Проигрыша нет, просто начинаете заново.
- **Дрифт** приносит очки, пока длится занос. Если врезаться посреди заноса, серия сгорает.
- **Пролёт впритирку** мимо машины трафика тоже даёт очки и деньги.
- Деньги идут ещё и за пройденный путь. На них в **гараже** покупаются машины.

| Машина | Цена | Макс. | 0–100 | Характер |
|---|---|---|---|---|
| Porsche Cayenne Turbo | бесплатно | 173 км/ч | 4.3 с | сбалансированная |
| Porsche 911 GT3 Touring | $ 6 000 | 184 км/ч | 3.4 с | самый острый руль |
| Ferrari 458 Spider | $ 18 000 | 198 км/ч | 3.1 с | охотно дрифтует |
| Porsche Carrera GT | $ 45 000 | 230 км/ч | 2.5 с | держит дорогу как на рельсах |

Скорости — игровые (город тесный, на настоящих 300 км/ч в нём не развернуться).

Когда денег хватит на новую машину, игра сама об этом напомнит.

## Настройки и производительность

- **Графика → Авто** (по умолчанию): игра пытается поддерживать плавность, понижая или повышая внутреннее
  разрешение 3D-картинки (от 40 до 85 % экранного). Интерфейс всегда остаётся чётким.
- **Качество**: максимальное разрешение и тени на фасадах. Для скриншотов и мощных телефонов.
- **Скорость**: без теней и с низким разрешением. Выбирайте, если в «Авто» всё равно подтормаживает.
- **Показывать FPS**: счётчик кадров, разрешение рендера и число вызовов отрисовки.
- **Урон от голода**: включить или отключить потерю здоровья при нулевой сытости.
- **Управление**: стрелки ◀ ▶ (по умолчанию) или стик.
- **Руль**: мягкий, средний или острый. Для стрелок — как быстро руль доходит до полного поворота
  (0.3 / 0.18 / 0.11 с), для стика — насколько далеко вести палец.
- **Газ/тормоз стиком** (только в режиме стика): стик вверх — газ, вниз — тормоз.

Советы для Helio G85:
- выключите **режим энергосбережения**: он ограничивает частоту процессора и видеочипа;
- закройте тяжёлые приложения в фоне;
- играйте с иконки на главном экране: там нет панели браузера и картинка больше.

## Известные ограничения

- Машины трафика на перекрёстках иногда проезжают сквозь друг друга (на игрока это не влияет).
- Город один и тот же при каждом запуске. Так удобнее запоминать маршруты.
- У Ferrari тормозные суппорты нарисованы на кузове и не поворачиваются вместе с колёсами.
- Угон — ранний вариант: водитель появляется при угоне и убегает, но у машин
  нет анимации дверей и полноценной анимации захвата/вытаскивания водителя.
  Угнанные машины не добавляются в гараж. Оружие, полиция и сюжет ещё не реализованы.
- Входы есть у многих отмеченных фасадов, но не у всех зданий. Интерьеры домов и
  магазинов повторяются; переход происходит с затемнением, без анимации двери.
  Положение в комнате не сохраняется после перезапуска: новый сеанс начинается
  на улице рядом с машиной. Заставка телевизора не является трансляцией.
- Это ограниченный набор взаимодействий, а не возможность использовать каждый
  объект города: два рецепта, пять работ и два комплекта одежды. Быстрый вызов
  такси в рюкзаке — мгновенный трансфер; работа таксистом — отдельная поездка
  под управлением игрока. Не более четырёх прохожих появляются рядом с игроком;
  один из них используется как пассажир. В домах нет отдельных обитателей.
- Падение после наезда и посадка — упрощённые анимации, не полноценный ragdoll
  и не анимация открывания дверей. Погибшие исчезают примерно через 20 секунд;
  полиция и долговременные последствия для города пока не реализованы.
- Модели героев созданы на базе готовых данных MakeHuman, а не полностью с нуля;
  их происхождение и условия описаны в `assets/characters/README.md`.
- Реальная плавность зависит от устройства, браузера, нагрева и настроек. Эмуляция
  в настольном браузере не заменяет тест на телефоне и не гарантирует частоту кадров.

**Тесты логики** (город, трафик, геймплей, коллизии, пешеход, камера и помещения):
`node --test tests/*.test.mjs`.
Отдельная симуляция физики машин: `node tests/physics-sim.mjs`.

**Браузерные тесты** (headless Chromium: езда, мультитач, герой, сохранение,
вход/выход, офлайн, полный экран, гараж, настройки, модели машин и трафика):
```
node tools/server.mjs 8080          # в отдельном окне
cd tests/e2e && npm run setup        # один раз
npm run all                          # скриншоты пишутся в tests/shots/
npm run character                    # только герой, мультитач, сохранения и офлайн
npm run hijack                       # пеший старт, угон, гараж, сохранение и офлайн
npm run interiors                    # направления камеры, дома, магазины, выход и офлайн
npm run home                         # бытовые действия, оба героя, сохранения и офлайн
npm run life                         # покупки, готовка, здоровье, одежда, задания, быстрый трансфер и офлайн
npm run work                         # работы, сенсорный газ, наезды, сохранение и офлайн
npm run fullscreen-fallback          # отказ/отсутствие Fullscreen API и портретный экран
npm run githack                      # URL с глубоким путём и редиректами файлов
LEGACY_GAME_ROOT=/путь/к/старой/game npm run upgrade  # необязательный тест настоящего обновления
```
Параметры адреса для отладки: `?shot` (принудительно «Качество»), `?noaudio` (без звука).

После изменения файлов поднимите версию `CACHE_VERSION` в `sw.js`, иначе установленная игра
будет показывать старую версию.
