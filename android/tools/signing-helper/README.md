# Локальное создание ключа Android

Эта страница создаёт **новый** ключ в браузере пользователя. Она не извлекает
прежний ключ из APK. APK, подписанный новым сертификатом, не установится как
обновление поверх APK с другой подписью; удаление старого приложения может
стереть его локальные данные.

Запуск для разработки:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory android/tools/signing-helper
# открыть http://localhost:8765/ (Web Crypto требует HTTPS или localhost)
node --test android/tools/signing-helper/keygen.test.cjs
```

Нажмите «Создать новый ключ», сохраните оба файла и добавьте два секрета в
настройках GitHub Actions вручную:

- `OPENSTREET_KEYSTORE_BASE64` — base64 содержимого PKCS#12, **без** архива и переносов строк;
- `OPENSTREET_KEYSTORE_PASSWORD` — пароль из отдельного файла.

Alias в PKCS#12: `openstreet-release`. Пароль ключа и хранилища одинаковый.
**Эта страница не создаёт GitHub Actions workflow и не подписывает APK.** Сборке
нужно декодировать base64 в приватный временный файл и записать пароль в другой
приватный временный файл для существующих `OPENSTREET_KEYSTORE` и
`OPENSTREET_STOREPASS_FILE`; файлы нельзя печатать в лог, добавлять в Git или
выгружать как артефакты. Готовый сертификат следует проверять по отпечатку.

Ключ RSA-3072 создаётся `crypto.subtle.generateKey`, 256-битный случайный пароль
— `crypto.getRandomValues`. Сертификат подписан SHA-256; PKCS#12 шифрует ключ
AES-256, alias указан явно. Код работает только в браузере: не использует
хранилища браузера, POST, fetch или внешние сервисы; CSP запрещает сетевые
API-запросы страницы. Ссылку на GitHub открывает сам пользователь. Скачанные
на устройство файлы следует хранить отдельно и приватно.
Пока пользователь не сохранил файлы и не добавил секреты, перезагрузка страницы
уничтожит единственную копию. Если файлы сохранены, их можно снова открыть через
«Уже создавали ключ? Загрузить сохранённые файлы»; проверяется пароль, alias и
соответствие открытого ключа сертификату. Кнопки скачивания не доказывают, что
файлы надежно сохранены: необходимо проверить их наличие и сделать резервные
копии.
