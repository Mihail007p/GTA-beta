OPEN STREET · ANDROID

Новый ключ для игры

Создайте закрытый ключ на этом устройстве и сохраните его в GitHub Secrets. Страница ничего не отправляет сама.

Важно: этот ключ не совпадает с подписью первого APK. Для новой сборки старую установленную игру придётся удалить; её локальные сохранения могут потеряться.

1 Создайте ключ

Ключ и пароль появятся только на этом устройстве. Не закрывайте страницу, пока не скачаете резервные копии и не добавите оба секрета в GitHub.

Создание может занять до минуты.

Уже создавали ключ? Загрузить сохранённые файлы

Если страница закрылась, выберите оба скачанных файла. Они останутся в браузере и не будут отправлены на сервер.

2 Сохраните резервные копии

Скачайте оба файла. Храните их приватно и отдельно друг от друга: они понадобятся, если GitHub Secrets потеряются. Не отправляйте их в чат.

3 Добавьте два секрета

Откройте страницу GitHub в соседней вкладке. Для каждого секрета нажмите New repository secret, укажите имя и вставьте значение. Затем нажмите Add secret.

✓ Готово

Когда оба секрета добавлены и резервные файлы скачаны, вернитесь в чат и напишите только «готово». Не присылайте значения секретов.

Отпечаток сертификата (не является секретом)
Ключ создаётся в браузере через Web Crypto. Страница не сохраняет данные на сервере и не отправляет их автоматически.
